# Interview Question Answers

For new answers, create a Markdown file in `Answers/` named `Q-<question-id>_<short-title>.md`. The build automatically maps the filename ID to the matching question and adds a **View answer** button. Rebuild with `node build-static.mjs` to publish the answer.

If the question's current bank ID differs from the ID in the source filename, add an HTML comment at the top with its current ID: `<!-- bank-question-id: Q-<current-question-id> -->`.

The legacy answer format below is still supported. IDs are based on the question text, technology, and topic; keep those unchanged after adding an answer so the answer stays linked.
